# Полный русификатор для игры USC: Counterforce. Заменяет венгерский язык (magyar) на русский. Инструкция по установке предоставлена ниже.

---

## 📥 Установка

### 1. Скачайте файл модифицированного data.unity3d
Скачайте файл **`data.unity3d.html`** (это перенаправление на Google Drive, где лежит модифицированный `data.unity3d`), либо перейдите по ссылке ниже:

> 🔗 [Скачать мод. data.unity3d (Google Drive)](https://drive.google.com/file/d/1mUC4Ql7pXUET48u6uGoLEmn9zyzFtbUq/view?usp=drive_link) (НЕАКТУАЛЬНО!)

### 2. Откройте скачанный файл
Дважды кликните по **`data.unity3d.html`** — вас автоматически перенаправит на Google Drive, где можно будет скачать **модифицированный файл `data.unity3d`** (вес ~11 ГБ).  
Сохраните его в удобное место (например, на рабочий стол).

### 3. Найдите папку с игрой
В Steam:
- Нажмите правой кнопкой мыши на **USC: Counterforce** в библиотеке.
- Выберите **«Управление» → «Просмотреть локальные файлы»**.

Откроется папка с игрой.

### 4. Перейдите в папку `USC Counterforce_Data`
Внутри папки с игрой найдите папку **`USC Counterforce_Data`**.  
В ней лежит **оригинальный** файл `data.unity3d`.

### 5. ⚠️ Сделайте резервную копию (обязательно!)
Перед заменой **скопируйте оригинальный `data.unity3d`** в другое место на вашем компьютере. Это позволит легко восстановить игру в случае проблем.

**Также вы можете восстановить оригинальный файл через Steam:**
- Нажмите правой кнопкой мыши на игру в библиотеке.
- Выберите **«Свойства…» → «Установленные файлы» → «Проверить целостность файлов игры»**.
- Steam сам скачает изначальный файл, и игра вернётся к исходному состоянию.

### 6. Замените файл
- **Скопируйте** модифицированный `data.unity3d` (который вы скачали с Google Drive) в папку `USC Counterforce_Data`.
- **Подтвердите замену** оригинального файла.

---

## 🎮 Запуск и проверка

Запустите игру. В настройках языка выберите **«magyar»**  
Интерфейс должен переключиться на **русский язык**.

> 💡 Почему «magyar»?  
> Кнопка переключения языка в игре ищет язык по имени, а не по индексу. Чтобы не переписывать код, я с помощью ИИ (DeepSeek, Claude) **заменил содержимое венгерского языка на русский**, оставив его название нетронутым. Так кнопка находит язык, а игрок видит русский текст.

---

## 📝 Примечания

- Русификатор **не влияет** на достижения и сохранения.
- Перевод сделан с помощью Google Translate, поэтому возможны неточности. Если найдёте ошибки — сообщите, исправлю!
- Если вы хотите **откатить** изменения — просто замените модифицированный файл на резервную копию оригинального `data.unity3d`, либо проверьте целостность файлов игры через Steam.
